## Reuse research

Reviewed https://github.com/tuanpham-dev/react-invoice-generator before development. MIT license (copyright Tuan Pham 2021), React 18 / TypeScript / Vite / react-pdf, last repository push reported 2024-05-27; not archived. It offers reusable invoice/PDF patterns but would add a separate React toolchain and is not the user's Korean two-copy form. No code imported from it. Reusing the user's plain HTML/CSS/JS form is smaller and preserves their current layout and business fields. MIT terms would require retaining its copyright/license if code were later copied.

## Public routes and search signals

- `/tools/` links both tools and is reachable from the main navigation.
- `/tools/manual-invoice/`: 15 rows, A4 landscape, optional VAT, previous balance/payment totals.
- `/tools/simple-receipt/`: 15 rows, A4 portrait, receipt amount, no extra VAT calculation.
- Each tool has its own canonical, title/description, server-rendered guide and contact, WebApplication + matching FAQPage + BreadcrumbList JSON-LD. Forms use a dedicated stylesheet rather than global marketing CSS to protect print layout.
- `rssSections` includes `tools`; Hugo's existing RSS template includes the guides, business options and contact. Sitemap is generated by Hugo. Feed publication is not proof of Naver RSS acceptance or search indexing.
- Existing IndexNow script now fails on non-2xx, deduplicates same-host HTTPS URLs and times out. HTTP 200/202 means receipt only, not search exposure. Existing automatic schedule is unchanged.
- Free form is the delivered functionality. Supplier/buyer information management, employee permissions and Type A/Type B pricing are consultation options, not a claim that account registration or billing is live.
